Warm, grounded, distinctive. Expert without hype; warmth in service of authority, never cuteness.

  • Speak to developers as peers.

Design Decisions

  • The One Accent Rule. Exactly one accent element per viewport: a CTA button OR an urgency badge OR an accent dot; the mobile sticky CTA yields.
  • No accent variants. Opacity for hover/active states.
  • Green = structural identity (logo, navigation, badges, links); orange = action (CTA buttons, urgency) only.
  • The Vivid Text Ban. #00c638 is never text on light (2.5:1); the retired --green alias stays retired, name tokens explicitly.
  • The Two-Tier Green Rule. Links get Brand Green (AA); green body text gets Deep Green (AAA).

Design Rationale

  • Crystalline triangles: agentic, structured, decomposable.
  • Leaf body: nature-digital; darker than the wings to read as anatomy.
  • Orange head: the mark's one accent and focal point.
  • Vivid antenna tips: saturation as dots, never as text.
  • Slot-6/7 fill asymmetry: a deliberate imperfection in color, not shape.
  • DK-B-V rule: faceted depth from three solid greens, no opacity or gradients.

Anti-Patterns (rejected variants)

  • No per-facet fill opacity (washed-out). The complete solid mark as a low-opacity ambient watermark is sanctioned: a whole-mark background treatment, not a dimmed wing.
  • No outlined-only wings (wireframe, not crystalline).
  • No fully symmetric fills; the slot-6/7 swap is locked.
  • No gradient fills; DK-B-V replaces them.
  • No stroke="none" on facets; the 0.5px fill-matched stroke kills anti-aliasing seams between triangles.
  • No shape-rendering="auto"; crispEdges is locked on the master.
  • Head r=8 locked; smaller reads as a dot, larger as a balloon.
  • No mono-colour butterflies; the DK-B-V triad is the identity.
9 — Rules & Anti-Patterns

Do

  • Use --green-brand for text on light backgrounds (AA)
  • Use --green-dark for body text needing AAA
  • Use --green-vivid for decorative elements and dark-mode links and labels
  • Use --accent for exactly one element per viewport — a CTA button OR an urgency badge, never both
  • Use asymmetric grids (1.4fr / 0.6fr), not 50/50
  • Use spacing rhythm — tight groupings, generous separations
  • Set line-height: normal on compact components
  • Light mode only. Dark sections for emphasis, not a toggle.

Don't

  • No --green-vivid as text on light — fails AA (2.5:1 on cream)
  • No multiple accent-colored elements in one viewport — one CTA button or one urgency badge or one accent dot, never two
  • No accent hover variants — use opacity for states
  • No cyan, neon, glassmorphism, gradient text, glow effects
  • No all-caps headings (except mono labels and trust bar)
  • No centered-everything layouts on desktop
  • No SVG blur/glow filters
  • No AI slop aesthetics (2024-2025 generic look)
  • No #8a8a80 as readable text — use --text-3 (#6b6b60) minimum

The Flat-By-Default Rule

A resting element that needs separation gets a 1px or 1.5px full border or a tint, never a shadow; shadows are state (hover, floating) or the one featured exception per page. The ghost-card pattern (border plus wide resting shadow) is prohibited. The whole shadow vocabulary:

  • Code ambient — 0 2px 8px rgba(28,28,26,0.04): the one resting shadow, under inline code snippets.
  • Hover lift — 0 8px 24px rgba(28,28,26,0.06) with translateY(-2px): interactive cards on hover only.
  • Tooltip — 0 8px 24px rgba(28,28,26,0.1): floating layers.
  • Featured glow — 0 4px 24px rgba(0,198,56,0.1): the featured pricing card; at most one per page.
  • Accent pulse — a ring keyframed from rgba(226,108,69,0.3) to transparent: the CTA heartbeat, 3s loop.

11 — Motion
The moving half of "Curious Play": choreography, not decoration. One signature easing curve; every animation lands on its static end state under reduced motion.
The Signature Moment

Crystalline Assembly

Each facet scales up from its own centre and settles into the locked mark, staggered outward from the body, head and antenna tips last; then wing-breathe and the light-shift. Geometry and colour never change. In the hero the same mark sits as a low-opacity ambient watermark.

Easing

  • --ease-settle cubic-bezier(0.16, 1, 0.3, 1). The signature: arrives fast, settles soft. Anything that lands (assembly, entrances, lifts).
  • --ease-calm ease-in-out. Anything that loops (wing-breathe, light-shift), so it reads as breathing, not as an event.

Duration

  • --dur-fast 150ms. State response: colour, opacity.
  • --dur-base 300ms. Default transition and hover lift.
  • --dur-settle 550ms. Crystalline assembly facet settle, wing flap.
  • --dur-entrance 700ms. Hero choreography.

Named Patterns

  • Crystalline Assembly — the signature. Facets settle into the locked mark on load, symmetric outward stagger.
  • Metamorphosis Refactor — the hero signature. The crystalline caterpillar becomes the locked mark while the synced code line becomes the agentic loop; detailed below.
  • Wing-Breathe — perpetual 2deg wing idle over 4s, starting after the assembly.
  • Light-Shift — a 7s brightness wave across the facets; brightness only, never a glow.
  • Hero Choreography — the hero text enters in five rise-and-fade steps.
  • Scroll Reveal — content fades and rises 16px as it enters the viewport, once.
  • Hover Lift — interactive cards rise 3px onto a soft shadow; the only resting-to-hover depth change.
  • Accent Pulse — the one warm action per viewport carries a 3s heartbeat ring.

Metamorphosis Refactor — the hero signature

On the homepage hero, a crystalline caterpillar crawls, cocoons, and unfurls into the locked mark while the code line beneath evolves into while(task) { explore → act → verify }: developer becomes agentic engineer, told twice at once. The synced code line is what makes the arc a domain claim instead of a transformation cliché.

  • Trigger — the hero mounts at rest; a single 5000ms timer after module boot fires one replay(); the arc plays exactly once. No scroll trigger, no auto-loop.
  • Movements — crawl 4.6s, gather 2.6s, chrysalis 3.0s, unfurl 3.4s, then rest; 13.6s. The 22 facets are constant; matter reorganizes. Motion is spring forces, never tweens; a deadband snap and shader rest gate land the rest pose byte-exact on the locked mark, which then breathes (Wing-Breathe, Light-Shift).
  • Code sync — the code block derives every beat from the module's phase clock (phaseInfo()), never wall clock, so creature and code cannot desync. Crawl types the loop body; gather and chrysalis hold it dimmed, cursor frozen; unfurl types while(task) ; rest holds the canonical line.
  • Gating and fallback — reduced motion, viewport at or under 900px, Save-Data, deviceMemory under 2, or missing WebGL2: no download, static poster plus finished line. Init failure, GPU context loss, sustained slow frames: same fallback, never freezing mid-refactor. The render loop pauses offscreen and on hidden tabs; loads over 2.5s mount at rest. A static or small-viewport telling of the same story is an open design task.
  • Locked assets — js/crystalline-metamorphosis.js (physics rig and choreography), the index.html hero (stage, inline poster SVG, Refactor block, gate script), metamorphosis-hero.html (lab: full arc on load, replay control), docs/metamorphosis-hero-prompt.md (design intent), tests/metamorphosis.spec.ts (byte-exact rest pose, reduced-motion poster, code resolution, DPR clamps, offscreen pause, teardown).
  • One locked unit — the animation and its synced code block ship together and are retimed together, never one side alone; the sequence resolves to the locked mark per the Mark-Motion Rule.

The Mark-Motion Rule

Choreographed motion that resolves to the locked mark is sanctioned; static effects (glow, gradient, drop-shadow, per-facet opacity, outline-only wings) stay banned. Motion animates the mark; it never restyles it.

The Reduced-Motion Rule

Every animation has a prefers-reduced-motion branch that lands on the static end state instantly. Shipping without one is a defect, not a polish item.
