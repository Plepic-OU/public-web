Claude Code Course Curriculum

6 Sessions: Ad Hoc Agents to a Repeatable Method

Curriculum built on Claude Code

6 Fridays · 9:00–15:30 · via Google Meet

Using a different agent? Why Claude Code →

Harness → Context → Verification → Scale

Lectures
  • Claude Code and the agentic loop: prompts, tokens, skills, subagents, MCP, plans and pricing
  • Hooks: observe every tool call, block the dangerous ones
Workshops
  • Devcontainer setup, then /init your own CLAUDE.md against a 150k-line repo
  • Build a guard hook; your breakout room then probes it with prompts until it holds
Lectures
  • Maps of the project: layered summaries, the C4 model, tokens vs the prompt cache
  • Design docs, the testing pyramid, validation loops and subagents in depth
Workshops
  • Build a C4-model skill and a DB-schema map, wired into CLAUDE.md
  • Prompt engineering, write-then-compare: write yours cold, run it, then run the reference. The delta is the lesson
  • Write a spec with acceptance criteria the agent can verify, checked by parallel validation agents
Lectures
  • From validated spec to working code; the two gates every change must pass: e2e and performance
  • Loop engineering: turn-based, goal-based, time-based and proactive loops (Anthropic’s “Getting started with loops”)
Workshops
  • Implement the spec in chunks; a validator subagent checks each one, then a /code-review loop runs until no issues remain, with a second review by another vendor’s model
  • Build the verification gate: a Lighthouse runner with a baseline diff and gated exit codes
  • Breakout: one ambitious goal per room. Divide the work, pick a presenter, ship
Lectures
  • Introspection and observability: session logs, /insights, OTEL metrics
  • Agent-native architecture, and proactive loops that run without you: log analysis, slow-query triage, payment matching
Workshops
  • Complete 2–5 GitHub issues in parallel, each agent in its own worktree
  • A measurable improvement loop: speed up the test suite or raise the Lighthouse score, both gates staying green

Apply the whole workflow in your company’s actual codebase, with instructor support. The weeks participants rate highest.

Deliverables
  • A configured agentic setup: CLAUDE.md, skills, hooks, gates
  • A real feature shipped through the full workflow, with the spec, ADRs and C4 diagrams
  • Final presentation and peer review
