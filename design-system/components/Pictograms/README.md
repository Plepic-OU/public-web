# Pictograms

Plepic's one icon set, copied from the curriculum sprite in `training/index.html`.

- Markup: the `<symbol>` sprite once per page, then `<svg class="cpath-icon"><use href="#i-name"/></svg>`. The consumer sets the colour through `color`.
- Files: the `Icons` asset group, one SVG per pictogram, drawn in `text`.
- Rules: the README's Iconography section.
