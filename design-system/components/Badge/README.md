# Badge

A short true state, in the one shape that is not a rounded rectangle: the `--rounded-badge` corner.

- Markup: `<span class="badge badge-default"><span class="badge-dot"></span>Label</span>`. The consumer supplies one to three words.
- `.badge-default` carries a `green-vivid` dot, the badge's only green.
- `.badge-urgency` carries an `accent` dot and spends the viewport's one accent, so no call-to-action button shares its view.
- Never put a price, a date or a count in a badge in design material.
