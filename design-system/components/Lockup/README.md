# Lockup

The wordmark and the mark as one unit: "Plepic" in Bitter 600 left, the butterfly right, `space-sm` apart.

- Markup: `<a class="logo-lockup">` with `<span class="logo-wordmark">Plepic</span>` and the mark's inline SVG (`.logo-butterfly`). Copy the SVG; never redraw it.
- `.logo-lockup--stacked` puts the mark above the wordmark for a narrow or centred space.
- Inside `.on-brand` (a `green-brand` ground) the wordmark turns `text`. The mark never changes.
