# Nav

The header's links: quieter ink at rest, full ink on hover, `green-brand` and underlined for the current page.

- Markup: `<nav class="nav">` holding `<a>` links; mark the current page with `aria-current="page"`.
- An external link (`target="_blank"`) earns a ↗ arrow, nothing more.
- The last item may be `.nav-cta`, an ink outline: the hero's primary button owns the viewport's accent.
