# CodeBlock

A short block of commands or code, in `mono-code`.

- Markup: `<div class="code-block code-block-default">` with lines separated by `<br>`. Wrap a comment in `<span class="comment">` (`text-3`) and a keyword in `<span class="keyword">` (`green-brand`).
- `rounded-sm`, a 1px `border` on `surface`.
- Ligatures stay off: JetBrains Mono would turn a double hyphen into one long dash and rename every flag.
