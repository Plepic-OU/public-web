# Button

The site's button: three sizes by three variants.

- Markup: an `<a>` or `<button>` with `.btn` and one variant, `.btn-primary`, `.btn-outline` or `.btn-ghost`, plus `.btn-lg` or `.btn-sm` for the other sizes. The consumer supplies the label.
- Rules: the Components section, "The button system" and "Primary plus ghost, never two solids".
