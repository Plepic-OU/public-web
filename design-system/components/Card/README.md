# Card

The instructor card: a graded editorial column that a rule opens above the eyebrow and a rule closes under the role. Nothing else draws a box.

- Markup, in source order: `.tt-seat` (owns hover and tilt) › `article.tt-card` › `p.tt-type` eyebrow › `h3.tt-name` with the mark as `.tt-setglyph` › `.tt-art` › `.tt-ink` › `img.tt-portrait` › `p.tt-role` with the employer in `.tt-company`. The consumer supplies the name, the role line and a square portrait.
- Set the cards in 300px columns, `space-xl` apart, one height.
- At rest it is two rules on the page ground. On hover or focus it rises and a white sheet with `card-shadow-hover` prints beneath it.
- Every portrait takes the same `--photo-grade`. Never grade one face, never redraw a face, never rank a person with a tier, score or power bar.
- Its only warm pixel is the ember inside the mark, so a row of cards spends no accent.
