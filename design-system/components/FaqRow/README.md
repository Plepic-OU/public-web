# FaqRow

A question that opens to its answer: two hairlines and space, no box, no radius, no shadow.

- Markup: `<details class="faq-item">` with a `<summary>` question and a `<div class="faq-answer">` answer.
- The question is Hanken 600 at `fs-faq-q`; the answer is body text.
- Keep one question per row and answer it in the first sentence.
