# Panel

A box for content that must lift off the page, and only that: most things are a rule and some space.

- Markup: `<div class="panel-white">` with a `<p class="panel-header">` and its content.
- Never same on same: `.panel-white` sits on `bg`, `.panel-cream` on `surface`.
- A full 1px `border` and `rounded-xl`, no resting shadow.
- `green-surface` marks a favoured option only.
