# Logos

Every file is exported from the plepic.com header lockup and the tagline by `design-system/export-logos.mjs`, so none is redrawn. Multi-ink and locked: never recolour, re-facet or stretch.

- `plepic-mark.*`: the butterfly alone.
- `plepic-lockup.*`: one row. "Plepic" in `green-brand`, Bitter 600, the mark, then the tagline in two lines. The default.
- `plepic-lockup-stacked.*`: mark above, wordmark, tagline.
- `plepic-lockup-mark-first.*`: mark left, wordmark over tagline.
- `plepic-com-lockup.*`, `plepic-com-lockup-stacked.*`, `plepic-com-lockup-mark-first.*`: the same three with the domain wordmark, ".com" in `text-2`, for print, merchandise and the social card. The web uses the three without ".com".

`.pdf` is vector with the font embedded, `.svg` has the text as outlines, `.png` is transparent at eight times the header size.
