Plepic · Design system

Layout

One scale, one container, one rhythm. Vertical space separates most blocks, so the scale does more work than any component.

The space scale

Eight steps, each about a third larger. A value off this list is a mistake. Group tight, separate generously; even spacing everywhere reads as an unfinished wireframe.

--space-xs0.25rem · 4pxA gap inside a chip
--space-sm0.5rem · 8pxWordmark to mark; label to value
--space-md1rem · 16pxParagraph to paragraph
--space-lg1.5rem · 24pxA row's padding
--space-xl2rem · 32pxA panel's padding; the card grid's gutter
--space-2xl3rem · 48pxHeading to the block under it
--space-3xl4rem · 64pxA block to the next block
--space-4xl6rem · 96pxA section to the next section

The container

1120px wide at most, with a 2rem gutter that never collapses. When a page feels empty, the emptiness is vertical.

1120px content track · 2rem gutter either side

Rhythm

Four measurements set the page.

--space-4xlSection padding, top and bottom: why two sections read as two.
--space-3xlBlock to block inside a section.
--header-height64px. The header is fixed, so anchors pad by this plus --space-3xl.
backdrop-filter12px blur at 90% page ground, so content passes under the header legibly.

Breakpoints

Four, each because something measurably broke.

640pxBelow: the type ramp bottoms out
768pxBelow: one column, nav collapses to the toggle
900pxBelow: the hero's butterfly stage is hidden entirely
901 to 1014pxTwo hero columns while narrower than the container; the headline ramps

Two rules about arrangement

Asymmetric1.4fr / 0.6fr, never 50/50. A page split down the middle argues for neither side; the hero, comparisons and panel rows lean.
Not centredOn desktop, centring is for one short thing, never a page of them.
