Plepic · Design system

Layout

One scale, one container, one section rhythm. Vertical space is the only thing that separates most blocks, so the scale below is doing more work than any component on this canvas.

The space scale

Eight steps, each roughly a third larger than the last. A value not on this list is a mistake, not a nuance.

--space-xs0.25rem · 4pxA gap inside a chip
--space-sm0.5rem · 8pxWordmark to mark; label to value
--space-md1rem · 16pxParagraph to paragraph
--space-lg1.5rem · 24pxA row's padding
--space-xl2rem · 32pxA panel's padding; the card grid's gutter
--space-2xl3rem · 48pxHeading to the block under it
--space-3xl4rem · 64pxA block to the next block
--space-4xl6rem · 96pxA section to the next section

The container

1120px wide at most, with a 2rem gutter that never collapses. The container has never changed; when a page feels empty the emptiness is vertical.

1120px content track · 2rem gutter either side

Rhythm

Four measurements set the whole page.

--space-4xlSection padding, top and bottom. The only reason two sections read as separate things.
--space-3xlBlock to block inside a section.
--header-height64px. The header is fixed, so anchored content pads by this plus --space-3xl.
backdrop-filter12px blur behind the header at 90% page ground, so content passes under it legibly.

Breakpoints

Four, and each one exists because something measurably broke.

640pxBelow: the type ramp bottoms out
768pxBelow: one column, nav collapses to the toggle
900pxBelow: the hero's butterfly stage is hidden entirely
901 to 1014pxThe hero runs two columns while the page is still narrower than the container, so the headline ramps rather than arriving at its cap
