Pricing, Subsidy, Common Questions

Agentic engineering

What is agentic coding?

Agentic coding is a software development approach where an LLM uses tools in a loop to plan, write, test, and refine code autonomously. Unlike single-prompt AI, an agentic system iterates until the goal is achieved.

How is agentic AI different from ChatGPT?

ChatGPT responds to a single prompt and stops. An agentic AI runs in a loop: it plans, acts with tools (write files, run tests, search code), observes the results, and continues until the job is done.

What is Claude Code and why does it matter?

Claude Code is Anthropic’s terminal-based agentic coding tool. Unlike IDE plugins, it has full system access: read files, run commands, manage git, integrate with any tool in your pipeline. It is scriptable end to end, which is why we built our curriculum around it.

How long does the training program take?

The training runs over six Fridays, each a full day (9:00–15:30) via Google Meet. The program covers 50 academic hours; participants apply what they learn in their own codebases between sessions.

Is there a certificate at the end?

Yes. Participants who complete the program receive a Plepic Certificate of Completion in Agentic Development. It covers Claude Code, context management, and the full agentic loop.

Can my team join if they’ve never used Claude?

Yes. No prior Claude experience is required, only 2+ years of software development and access to a real codebase. The first session covers Claude Code setup from scratch.
